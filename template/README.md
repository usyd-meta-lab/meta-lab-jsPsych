# Experiment

A jsPsych experiment built with the [USYD Meta Lab kit](https://github.com/usyd-meta-lab/meta-lab-jsPsych).

Open this folder in Claude Code and describe what you want to change; Claude builds it and shows you a preview. To look at it yourself:

```bash
npm install
npm run dev
```

`npm install` is only needed the first time. `npm run dev` opens the experiment dashboard: click any part of the experiment to try it.

The kit's README explains setup, collecting data and updating the kit.
